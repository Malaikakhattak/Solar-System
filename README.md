# 🌌 Neon Solar System – 3D Computer Graphics Project

A 3D interactive solar system simulation developed as a **Computer Graphics academic project** using Python, Pygame, and PyOpenGL.

## ✨ Features

* 🌞 Animated glowing Sun
* 🪐 8 planets with individual orbital and rotation speeds
* 🌍 Earth with an orbiting Moon
* 💍 Saturn with rings
* ☄️ Animated asteroid belt
* ⭐ 2500+ multi-colored flickering stars
* 🌌 Nebula background effects
* 💡 OpenGL lighting and atmospheric effects
* 🏷️ Planet labels
* 🎮 Interactive camera controls
* 🔄 Real-time 3D animation

## 🛠️ Technologies Used

* Python
* Pygame
* PyOpenGL
* OpenGL / GLU
* Math
* Random

## 📋 Requirements

Make sure Python is installed on your computer.

Install the required libraries using:

```bash
pip install pygame PyOpenGL PyOpenGL_accelerate
```

## ▶️ How to Run

1. Clone or download this repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run:

```bash
python project.py
```

The 3D Solar System window will open.

## 🎮 Controls

| Key          | Action              |
| ------------ | ------------------- |
| ↑            | Zoom in             |
| ↓            | Zoom out            |
| ←            | Rotate camera left  |
| →            | Rotate camera right |
| Close Window | Exit the simulation |
